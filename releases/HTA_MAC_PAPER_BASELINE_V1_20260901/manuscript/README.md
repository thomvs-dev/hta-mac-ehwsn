# HTA-MAC Overleaf Package

Upload the contents of this folder, or upload the ZIP archive directly, to a
new Overleaf project. Set `main.tex` as the main document if Overleaf does not
select it automatically.

Recommended compiler: pdfLaTeX.

The package contains:

- `main.tex` - complete self-contained manuscript source with the IEEE-formatted
  bibliography embedded at the end
- Six image files referenced by the manuscript, stored beside `main.tex`

No BibTeX step, local paths, generated-data files, or repository source code
are required to compile the paper.
